# Security Best Practices

## Password Security

1. **Use Strong Passwords**
   - Minimum 16 characters
   - Mix of uppercase, lowercase, numbers, symbols
   - Never reuse passwords

2. **Use a Password Manager**
   - Store all passwords in encrypted vault
   - Use unique master password
   - Enable 2FA

3. **Password Generator**
   - Use built-in generator for new passwords
   - Adjust length based on sensitivity
   - Include all character types for sensitive accounts

## Encryption

- AES-256 encryption for vault
- Master password never stored
- PBKDF2 key derivation

## Tips

- Never share master password
- Lock vault when away
- Export backup securely
- Regularly rotate passwords
